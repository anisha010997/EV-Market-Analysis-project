# EV Market Analysis — Project Report

## 1. Overview
This project is a Tableau dashboard prototype for exploring electric vehicle specifications and sample market indicators.

## 2. Objectives
- Build an interactive view of EV categories and manufacturers.
- Compare sample battery capacity, range, price, and charging duration.
- Demonstrate filters, KPI cards, ranking charts, scatter plots, and geographic views.
- Prepare a reusable structure for later analysis with sourced real-world data.

## 3. Methodology
A synthetic dataset was created for dashboard prototyping. It contains 80 sample records with illustrative manufacturer/model names and generated specifications. The dataset is not collected from manufacturers or an official market source.

## 4. Suggested analysis
Once a verified dataset is supplied, investigate annual sales growth, manufacturer market share, range by battery chemistry, price-to-range trade-offs, regional production, and customer satisfaction. Validate field definitions and coverage before comparing groups.

## 5. Limitations
All rows in the included sample CSV are synthetic. Sample sales, prices, ratings, countries, ranges, capacities, and charging durations must not be presented as actual EV market facts. No real-world conclusions are claimed in this report.

## 6. Future work
- Replace synthetic records with a documented, licensed dataset.
- Record source URLs, collection date, geographic scope, and data-cleaning steps.
- Build and save a `.twbx` packaged workbook in the `tableau/` folder.
- Publish the finished dashboard to Tableau Public and add the URL to the README.
